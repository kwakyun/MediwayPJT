# 메디웨이 데이터 출처와 정제 기록

## 선택형 대중교통정보

- ODsay Server API 키가 설정된 경우에만 버스·지하철 경로를 호출한다.
- 총 소요시간, 대중교통 요금, 환승 횟수와 승·하차 지점은 ODsay 응답을 사용한다.
- 야외시간은 경로 내 도보 구간 시간의 합이며, 대중교통·대기시간은 `총 소요시간 - 야외시간`으로 분리한다.
- `추천`, `지하철`, `버스` 우선 경로를 선택할 수 있다. 요금과 경로는 교통 상황·운임 정책에 따라 실제 이용 시 달라질 수 있다.

## 적용 지역과 사용 원칙

- 대상 지역: 부산광역시 금정구
- 서비스는 안정적인 비교를 위해 기준일이 명시된 저장 스냅샷을 사용한다.
- 위치·환경·인구 정보는 의료 진단이나 실제 운영 여부를 보장하지 않는다.
- 병원급 후보 15곳, 진료과·운영 참고정보와 보행경로는 `메디웨이_금정구_MVP_데이터.xlsx`를 2026-07-14에 가져온 스냅샷이다.

## 운영시간 스냅샷

- 건강보험심사평가원 병원정보서비스는 신고 기반 병원정보를 실시간 갱신하지만 상세 API는 활용 신청이 필요하다.
- 서동가정의학과의원: 공식 홈페이지 `https://seodongfmc.com/28`, 2026-07-14 확인.
- 새우리남산병원: HIRA 기반 하이닥 병원찾기 `https://mobile.hidoc.co.kr/find/result/view/H0000153111`, 2026-07-14 확인.
- 화창한병원: 나만의닥터 병원정보 `https://my-doctor.io/hospital/detail?hospital_id=1758`, 2026-07-14 확인.
- 나머지 기관은 신뢰할 수 있는 시간표를 확인하지 못해 `운영시간 확인 필요`로 표시한다.
- 앱의 `진료 중` 표시는 한국 시간과 저장된 정규 시간표를 비교한 결과이며 실시간 접수, 임시 휴진, 공휴일 변경, 진료과별 일정을 보장하지 않는다.
- 금정구 의료기관 스냅샷의 서동가정의학과의원 전화번호 자리표시 값은 공식 홈페이지 번호 `051-521-7818`로 정제 단계에서 교정했다.
- 날씨와 대기질 CSV는 실시간 관측값이 아닌 빠른 검색용 기준 조건이며 화면에서는 `서비스 기준 환경 정보`로 안내한다.

## 시설 데이터

- 의료기관 원천: [공공데이터포털 - 부산광역시 금정구 의료기관 현황](https://www.data.go.kr/data/3078698/fileData.do), 기준일 2024-03-05, 원천 363행.
- 약국 원천: [공공데이터포털 - 부산광역시 금정구 약국 현황](https://www.data.go.kr/data/15023362/fileData.do), 기준일 2025-09-05, 다운로드 파일 108행(포털 메타데이터 표기 111행과 차이가 있어 실제 파일 행 수를 기준으로 기록).
- 원천 파일은 `data/raw/`에 보존하고, 서비스 초기 제공 범위로 지역·진료과·생활권 분포를 고려한 병원 15곳과 약국 12곳을 등록했다.
- 주소 좌표는 OpenStreetMap Nominatim으로 2026-07-13에 변환하고 응답과 시각을 `data/raw/geocode_cache.json`에 보존했다. 지번이 등록되지 않은 주소는 도로 또는 건물 중심 좌표로 반환되어 같은 건물의 병원·약국이나 인접 번지가 겹칠 수 있으며 앱 지도에서 순위별 오프셋으로 구분한다.
- 진료과목은 원천 파일에 없으므로 기관명에서 명시된 진료과를 표준화했다. 병원급 6곳은 질환별 접근성 비교를 위해 대표 진료과를 별도 규칙으로 부여했다. 실제 진료 가능 여부는 기관 확인이 필요하다.
- 표준 명칭: `가정의학과`, `내과`, `소아청소년과`, `신경과`, `이비인후과`, `정형외과`, `재활의학과`, `응급의학과`, `외과`, `신경외과`, `약국`.

## 인구 데이터

## 경로·시설 접근성 프로필

- `walking_routes.csv`에는 부산대역·구서역·노포역 기준 OSM/Valhalla 근사 보행경로 45건과 서동역 좌표 미확인 15건이 있다.
- `facility_accessibility.csv`의 무단차·엘리베이터·장애인 주차 정보는 모두 미확인이다. 확인 전에는 동일한 중립값으로 처리한다.
- 날씨와 대기질은 공통 점수가 아니라 시설별 야외 노출시간과 사용자 민감도에 적용한다.
- 경로는 공개 데모 기반 근사치이며 실시간 교통, 정밀 고도, 공사, 횡단보도와 보도 상태를 반영하지 않는다.
- 원본에 도로 중심선 수준의 중복 좌표가 있어 실제 서비스 전 재지오코딩이 필요하다.

## 추가 평가 입력 데이터

- `clinical_condition_inputs.csv`는 병원 15곳의 공개 진료과, 야간·토요일·일·공휴일 진료, 24시간 응급 및 재활·수술·전문의·협진 공개 근거를 담는다.
- 진료 가능 시간은 야간 30%, 토요일 25%, 일·공휴일 25%, 24시간 응급 20%로 운영 접근성 점수를 계산한다. 이는 의료 수준이나 치료 적합도 평가가 아니다.
- `facility_accessibility_inputs.csv`는 기관별 3개 출발지 보행경로 관측과 공개 주차 근거를 담는다. 기존 출발지별 경로 점수와 중복되지 않도록 보행 관측 수는 데이터 근거 수준에만 반영한다.
- 무단차 출입구·엘리베이터·장애인 주차·장애인 화장실·접근 동선의 `unknown`은 가감하지 않는다. 확인된 인근 장애인 주차와 주차 안내만 제한적으로 시설 접근성에 반영한다.
- 공개 출처와 수집 상태는 데이터 근거 점수에 반영하며, 이 점수 역시 시설 품질을 뜻하지 않는다. 모든 운영·시설 정보는 방문 전 기관 확인이 필요하다.

- 원천: [금정구청 - 주민등록 인구현황](https://www.geumjeong.go.kr/board/view.geumj?boardId=BBS_0000032&dataSid=977361&menuCd=DOM_000000127002001003), 기준일 2026-03-31.
- 금정구 전체 주민등록 인구 206,033명, 65세 이상 59,484명이며 행정동별 값을 함께 저장한다.
- 외국인 포함 여부 등 세부 집계 정의는 원천 엑셀과 금정구청 설명을 따른다.

## 날씨와 대기질

- 날씨 항목 구조의 참고 기관: 기상청. 본 저장값은 실시간 관측이 아니라 맑음/비 검색 기준 조건이다.
- 대기질 등급: [AirKorea 미세먼지 행동요령](https://m.airkorea.or.kr/info/behaviorInfo1)의 예보 구간을 적용했다. PM10은 좋음 0~30, 보통 31~80, 나쁨 81~150, 매우 나쁨 151 이상이며 PM2.5는 좋음 0~15, 보통 16~35, 나쁨 36~75, 매우 나쁨 76 이상이다.
- 단위: 기온 °C, 강수량 mm, PM10·PM2.5 µg/m³.

## 재현과 품질 검사

```powershell
python scripts/prepare_data.py
python scripts/validate_data.py
```

`prepare_data.py --geocode`는 좌표 캐시를 새로 만들 때만 네트워크가 필요하다. 앱 실행과 검증에는 네트워크가 필요 없다.
