< 팀프로젝트 평가기준 >



  제출 항목   :     다음의 3가지 항목을 제출한다.

     

(2) 프로젝트 보고서 파일  ( 워드  or  PPT  파일 )
                              :  프로젝트 개요(제목,주제선정 이유 및 필요성, 목표)
                              :  프로젝트 수행 내용 ( 업무 분담 및 수행 절차, 주요 기능, 결과물 설명, 기존 사례와의 차별점 )
                              :  기대 효과 및 프로젝트 수행 결과 느낀점

                        (3) 발표 영상 파일 ( 8분 정도 )
                              : 제목, 주제선정 이유, 데이터셋 설명(2~3분) + 웹대시보드 시연(4~5분) +  결론 및  어필(1분)


 

< 팀프로젝트 평가 내용 >


   평가 방법   :     (1) 발표영상 보기  ->  (2)  질의응답하기  ->  (3) 점수 매기기 

   평가 점수    :     팀 간 상호평가(30)     +    교수자 평가(20)

                             - 팀 간 상호평가  :  본인 팀을 제외한 다른 6개 팀에게 받는 점수  (상-5점, 중-3.4점, 하-1.7점)
                                                                각 팀은 6개팀중에서,  상(2팀) / 중(2팀) / 하(2팀) 으로 최종 결정해야 함.
                             - 교수자 평가       :   담당 교수에게 받는 점수

   1. 팀 간 상호 평가 항목

       ① 주제 선정 및 문제 정의
            분석하고자 하는 주제가 흥미롭고, 가설이 명확하고 타당한가?
               데이터를 통해 해결하려는 목적이 설득력 있게 다가왔는가?

       ② 데이터 분석 및 기술적 완성도
            주제에 적합한 데이터셋을 사용하고, 분석 과정이 논리적인가?
               단순 통계를 넘어 의미 있는 인사이트를 깊이 있게 다루었는가?

        ③ 대시보드 구현 및 UI
               사용자가 이해하기 쉽게 차트와 시각화 요소가 직관적으로 구성되었는가?
               대시보드의 인터랙션(필터, 사이드바 등)이 매끄럽고, 스토리텔링이 포함되어 있는가?

        ④ 발표력 및 전달력
            분석 결과와 대시보드 시연 과정을 제한 시간 내에 효과적으로 전달했는가?
               질의응답에 대해 논리적이고 명확하게 답변하였는가?

   2. 교수자 평가 항목

        ① 프로젝트 결과물이 완성도가 있는가?  (10점)
          ② 아무 잡음없이 전체 팀원들의 협업으로, 1차/2차 모든 제출 항목을 기한내 정상 제출하였는가?   (5점)
          ③ 좋은 평가자로서 다른 팀의 프로젝트 결과물에 대하여 객관적이고 공정하게 성의있는 평가를 수행하였는가?  (5점)
