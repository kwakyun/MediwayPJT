# 제출 체크리스트

## 제출물 3종

- [x] 실행 파일 `app.py`, 의존성 `requirements.txt`, 저장 데이터, 실행 안내
- [x] PPT 보고서 `output/report/메디웨이_프로젝트_보고서.pptx`
- [ ] 약 8분 실제 발표 영상: 2~3분 설명 / 4~5분 시연 / 1분 결론

## 제출 직전 확인

- [ ] 팀원 이름·실제 역할·산출물·상호 검토를 `docs/team_contribution.md`에 입력
- [ ] 1차·2차 제출 담당자, 기한, 완료 시각, 확인자 입력
- [ ] 실제 영상 길이·음성·화면·자막·수치·재생 확인
- [ ] 다른 컴퓨터에서 패키지 압축 해제 후 `python -m streamlit run app.py` 실행
- [ ] 팀원 2명 이상이 파일명·크기·수정 시각·열기 여부 교차 확인
- [ ] 제출 시스템 업로드 후 다시 내려받아 열기·실행·재생

임의의 팀원 이름이나 제출 완료 상태를 기록하지 않는다. 실제 증거가 생긴 뒤 체크한다.
