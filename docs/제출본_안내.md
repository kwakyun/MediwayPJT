# 메디웨이 최종 제출본 안내

## 제출 항목

1. `01_웹대시보드_소스/` — Streamlit 앱, 실행 데이터, 테스트 코드
2. `02_프로젝트_보고서/` — 프로젝트 개요·수행 내용·결과·업무 분담·기대 효과가 포함된 PPT
3. `03_발표자료_및_발표문/` — 서비스 소개 PPT와 8분 발표문
4. `04_검증결과/` — 대표 시나리오 결과와 품질 확인 문서

## 실행 방법

압축을 푼 뒤 `01_웹대시보드_소스` 폴더의 `run_app.bat`을 더블클릭합니다. 최초 실행 시 가상환경과 필수 패키지를 자동으로 설치한 뒤 브라우저에서 앱을 엽니다. 수동 실행이 필요한 경우에만 다음 명령을 순서대로 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

앱의 추천 기능은 포함된 `data/processed/` 데이터를 사용하므로 실행 중 인터넷 연결이 없어도 작동합니다. ODsay·Gemini API 기능은 `.streamlit/secrets.toml.example`을 `.streamlit/secrets.toml`로 복사한 뒤 개인 키를 입력하면 활성화됩니다. 키가 없거나 API가 응답하지 않더라도 저장 데이터 기반 추천과 기본 상담은 계속 작동합니다.

`현재 위치 받기`는 브라우저 위치 권한이 필요하며 HTTPS 배포 주소 또는 `localhost`에서 동작합니다. 권한을 허용하면 현재 위치 기준으로 거리·추천·지도·대중교통 출발점을 다시 계산합니다.

`메디웨이 상담`은 Gemini 키가 있으면 서비스 맥락과 일반 의료지식을 결합한 AI 강화 모드로 동작하며, API 사용이 불가능할 때는 저장 데이터 기반 CS 모드로 자동 대체됩니다. 의료 진단·처방 용도가 아니며 응급 질문은 119 안내를 우선합니다.

## 발표 순서

`03_발표자료_및_발표문/메디웨이_서비스소개_레퍼런스리디자인.pptx`를 열고 `발표문_8분_서비스중심.md`의 시간표에 맞춰 발표합니다. 4번 슬라이드에서 웹대시보드 시연으로 전환하고, 시연 후 5번 슬라이드부터 이어갑니다.

## 주의사항

- 실제 API 키가 든 `.streamlit/secrets.toml`은 공개 저장소나 공개 게시판에 업로드하지 않습니다.
- 평가기준의 발표 영상은 `03_발표자료_및_발표영상/`에 약 8분 분량의 영상 파일을 추가한 뒤 제출합니다.
- 점수는 병원의 의료적 우수성이나 치료 적합도가 아니라 이동 접근성 비교값입니다.
- 부산대역·구서역·노포역 경로는 OSM 기반 근사치입니다.
- 서동 경로와 시설 접근성은 미확인 상태가 포함되어 있습니다.
- 운영정보가 없으면 공개 운영 안내 또는 전화번호를 제공합니다.
- 대중교통 요금과 경로는 ODsay 조회 시점 기준이며 실제 운임·운행 상황과 다를 수 있습니다.
