# 메디웨이 화면 구현 계약

## 공통 구조

- 상단 내비게이션: `의료기관 추천` → `지역 의료 현황` → `추천 기준 안내` 순서로 고정한다.
- 공통 헤더: 서비스명, 이동 부담을 함께 고려한다는 핵심 문장, `부산 금정구 맞춤 검색` 배지를 표시한다.
- 공통 하단: 이동 접근성 참고 정보, 직선거리, 운영·진료 가능 여부 미보장, 데이터 기준일을 표시한다.
- 추천 카드의 `운영시간·상세 보기`를 누르면 시간표 기준 현재 상태, 오늘 시간, 점심시간, 공휴일, 확인일과 출처를 표시한다.
- 확인되지 않은 기관은 운영 여부를 추정하지 않고 전화 확인을 안내한다.
- 멀리서도 읽기 쉬운 가독성을 유지한다. 페이지 제목 32px 이상, 핵심 수치 40px 이상, 본문 18px 이상을 사용한다.

## 추천 화면 와이어프레임

```text
┌ 서비스명 · 핵심 문장 ─────────────────────────────────────────┐
│ [빠른 조건 설정 ▼] [세부 검색 조건] [추천 결과 보기]             │
├ 현재 조건 요약 ─────────────┬ 날씨·대기질 카드 3개 ─────────────┤
│ 위치 / 사용자 / 질환 / 유형 │ 날씨 / PM10 / PM2.5               │
├ 1순위 추천 히어로 ─────────────────────────────────────────────┤
│ #1 시설명       81.6점       이동 7분 · 야외 3분               │
│ 대표 이유 1 · 대표 이유 2                                      │
├ TOP 5 카드 목록 ────────────┬ 순위 지도 ───────────────────────┤
│ #1~#5 시설·점수·거리·이유   │ 기준점 + 번호 마커               │
│ [점수 상세]                 │ 마커 팝업                        │
├ 출처 · 데이터 기준 · 서비스 한계 ───────────────────────────────┤
```

- 빠른 조건 선택과 `추천 결과 보기` 한 번, 총 2회 조작으로 결과에 도달한다.
- 빠른 조건은 위치, 기본 특성, 질환, 시설 유형, 날씨·대기질 기준을 한 번에 바꾼다.
- 질환은 질환군 펼침 → 세부 질환 복수 선택 순으로 제공하며 `선택 안 함`은 빈 선택으로 처리한다.
- 1순위 히어로는 시설명, 0~100점, km, 대표 이유를 첫 시선 영역에 배치한다.
- 카드와 지도는 `rank`와 `facility_id`를 단일 키로 사용한다. Streamlit의 지도 클릭 이벤트가 환경별로 불안정할 수 있어 카드 선택을 기본 연동 경로로 제공하고, 마커 팝업에는 동일 정보를 표시한다.

## 지역 의료 현황 화면

```text
┌ 전체 인구 ┬ 65세 이상 ┬ 선별 병원 ┬ 선별 약국 ┐
├ 시설 유형별 수(막대) ─┬ 인구 1만 명당 시설 수(막대) ┤
├ 행정동별 고령 인구 비율(막대) ────────────────────┤
└ 핵심 해석 + 전체 현황이 아닌 서비스 등록 시설 범위 ─┘
```

- 차트마다 제목, 단위, 기준일, 한 문장 결론을 함께 표시한다.
- 시설 지표는 선별 스냅샷 27곳 기준임을 숫자 바로 옆에 표시해 금정구 전체 현황처럼 오해하지 않게 한다.

## 추천 기준 안내 화면

- 가중치를 진료 조건 35% / 경로 편의 30% / 시설 접근성 20% / 운영정보 10% / 데이터 신뢰도 5%로 표시한다.
- `입력 → 직선거리 → 구성 점수 → 가중합 → TOP 5·이유` 흐름을 5단계로 표현한다.
- 데이터 출처·기준일·정제 방식과 네 가지 한계(직선거리, 운영·진료 미보장, 규칙 기반, 교통·보행 환경 미반영)를 표시한다.

## 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---:|---|
| `--navy` | `#102A43` | 제목과 본문 핵심 |
| `--blue` | `#0B6E99` | 버튼과 선택 상태 |
| `--teal` | `#0F8B8D` | 1순위 강조 |
| `--green` | `#18794E` | 좋음 |
| `--amber` | `#B45309` | 보통·주의 |
| `--red` | `#B42318` | 나쁨·오류 |
| `--surface` | `#F4F8FB` | 카드 배경 |
| `--border` | `#CCD9E2` | 경계선 |

- 흰색 배경에서 본문 색상 대비는 4.5:1 이상을 목표로 한다.
- 등급은 색상과 함께 `좋음`, `보통`, `나쁨` 텍스트를 표시한다.
- 순위는 색 대신 `#1`~`#5` 번호를 항상 표시한다.

## 상태와 복구 문구

| 상태 | 화면 | 다음 행동 |
|---|---|---|
| 초기 | 기본 검색 조건과 사용법 | `추천 결과 보기` 선택 |
| 로딩 | “거리와 환경 조건을 계산하고 있습니다” | 입력 유지, 중복 실행 방지 |
| 성공 | 조건 요약·히어로·TOP 5·지도 | 카드 또는 상세 보기 선택 |
| 결과 없음 | “조건에 맞는 시설을 찾지 못했습니다” | 시설 유형 또는 위치 변경 |
| 일부 누락 | 해당 값에 `정보 없음` | 기관에 직접 확인 |
| 데이터 오류 | “서비스 데이터를 불러오지 못했습니다” | 검색 조건 초기화 또는 재시도 |
| 계산 오류 | “추천 계산을 완료하지 못했습니다” | 입력을 유지한 채 재실행 |

## 반응형·접근성 승인 기준

- 1920×1080에서는 TOP 5와 지도를 5:7 비율의 두 열로 배치한다.
- 1366×768 이하에서는 히어로 → TOP 5 → 지도 순의 한 열로 읽히게 한다.
- 모든 입력에 보이는 라벨과 도움말을 둔다. 주요 동작은 표준 Streamlit 위젯을 사용해 키보드 접근을 유지한다.
- 지도만으로 시설을 식별하지 않으며 동일한 순위 목록을 먼저 제공한다.
- 긴 주소·출처·산식은 펼침 영역으로 보내 핵심 결과가 밀리지 않게 한다.
- 의료 진단·치료 적합성·실제 진료 가능성을 보장하는 문구는 사용하지 않는다.
