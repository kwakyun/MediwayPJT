# 메디웨이 다른 컴퓨터 실행 가이드

이 가이드는 개발 환경이 없는 Windows 10/11 컴퓨터에서 메디웨이 Streamlit 앱을 실행하는 방법을 설명합니다.

## 1. 준비물

- 인터넷 연결: Python과 라이브러리를 처음 설치할 때 필요
- 웹 브라우저: Microsoft Edge 또는 Google Chrome 권장
- 저장 공간: 약 1GB 이상 권장
- Python: 64비트 Python 3.11 또는 3.12 권장

Python 공식 다운로드: https://www.python.org/downloads/windows/

설치 화면에서 반드시 `Add python.exe to PATH`를 선택한 뒤 설치합니다. 설치가 끝나면 열려 있던 PowerShell이나 명령 프롬프트를 모두 닫고 새로 실행합니다.

## 2. 압축 해제

1. 전달받은 ZIP 파일을 마우스 오른쪽 버튼으로 클릭합니다.
2. `압축 풀기`를 선택합니다.
3. 가능하면 `C:\mediway`처럼 짧고 단순한 경로에 압축을 풉니다.
4. 압축을 푼 폴더에서 `01_웹대시보드_소스` 폴더를 엽니다.
5. 해당 폴더에 `app.py`, `requirements.txt`, `src`, `data`가 보이는지 확인합니다.

## 3. PowerShell 열기

`01_웹대시보드_소스` 폴더의 빈 공간을 Shift 키를 누른 상태에서 마우스 오른쪽 버튼으로 클릭하고 `터미널에서 열기` 또는 `PowerShell 창 열기`를 선택합니다.

프롬프트의 현재 경로 끝이 `01_웹대시보드_소스`인지 확인합니다.

## 4. Python 설치 확인

```powershell
python --version
```

`Python 3.11.x` 또는 `Python 3.12.x`가 표시되면 정상입니다.

`python` 명령을 찾지 못하면 다음 명령을 사용합니다.

```powershell
py --version
```

두 명령이 모두 작동하지 않으면 Python을 다시 설치하고 `Add python.exe to PATH`를 선택합니다.

## 5. 가상환경 생성

```powershell
python -m venv .venv
```

`python` 대신 `py`만 작동한다면 다음과 같이 실행합니다.

```powershell
py -m venv .venv
```

## 6. 가상환경 활성화

```powershell
.\.venv\Scripts\Activate.ps1
```

정상 활성화되면 명령줄 앞에 `(.venv)`가 표시됩니다.

스크립트 실행이 차단되었다는 오류가 나오면 현재 PowerShell 창에서만 다음 명령을 실행한 후 다시 활성화합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## 7. 필요한 라이브러리 설치

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

설치가 완료될 때까지 PowerShell 창을 닫지 않습니다. 네트워크 환경에 따라 몇 분 정도 걸릴 수 있습니다.

## 8. 메디웨이 실행

```powershell
streamlit run app.py
```

정상 실행되면 브라우저가 자동으로 열리고 다음과 비슷한 주소가 표시됩니다.

```text
http://localhost:8501
```

브라우저가 자동으로 열리지 않으면 PowerShell에 표시된 Local URL을 복사해 Edge 또는 Chrome 주소창에 붙여넣습니다.

Windows 방화벽 창이 표시되면 개인 네트워크에서 Python 또는 Streamlit의 접근을 허용합니다.

## 9. 처음 확인할 기능

1. 왼쪽 메뉴에서 `의료기관 추천` 화면이 열리는지 확인합니다.
2. 빠른 조건 설정을 선택하고 `추천 결과 보기`를 누릅니다.
3. 추천 TOP 5, 점수, 이동시간, 야외시간이 표시되는지 확인합니다.
4. `위치 지도` 탭에서 출발 위치와 추천 시설이 구분되는지 확인합니다.
5. `메디웨이 상담` 화면에서 지역 또는 병원 정보를 질문합니다.

현재 위치 기능을 사용할 때는 브라우저의 위치 권한을 허용해야 합니다. 위치 권한을 거부해도 미리 등록된 생활권 위치로 추천 기능을 사용할 수 있습니다.

## 10. API 키는 선택 사항

API 키가 없어도 저장된 데이터를 사용하는 의료기관 추천, 지도, 지역 현황과 기본 CS 상담은 작동합니다.

- ODsay API 키: 실시간 버스·지하철 경로, 요금과 환승 비교에 사용
- Gemini API 키: 일반 의료정보를 결합한 AI 강화 상담에 사용

일반 배포본은 `.streamlit\secrets.toml`을 직접 만들고 값을 입력합니다. 비공개 팀원 실행 패키지에는 이 파일이 포함되어 있어 별도 입력 없이 사용할 수 있습니다.

```toml
ODSAY_API_KEY = "발급받은_키"
GEMINI_API_KEY = "발급받은_키"
GEMINI_MODEL = "gemini-3.5-flash"
```

`secrets.toml`에는 실제 키가 들어 있습니다. 키가 포함된 팀원 실행 ZIP은 승인된 팀원에게만 직접 전달하고, GitHub·공개 드라이브·외부 제출본에는 포함하지 않습니다.

## 11. 앱 종료와 다시 실행

앱을 종료하려면 Streamlit을 실행한 PowerShell 창에서 `Ctrl + C`를 누릅니다.

컴퓨터를 다시 켠 뒤에는 `01_웹대시보드_소스` 폴더에서 다음 세 줄만 실행하면 됩니다.

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

가상환경 활성화가 어려우면 다음 한 줄로 직접 실행할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 12. 자주 발생하는 오류

### `streamlit` 명령을 찾을 수 없습니다

가상환경이 활성화되지 않았거나 라이브러리 설치가 누락된 상태입니다.

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

### `ModuleNotFoundError`가 표시됩니다

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

### `app.py`를 찾을 수 없습니다

PowerShell이 잘못된 폴더에 열려 있습니다. `app.py`가 보이는 `01_웹대시보드_소스` 폴더에서 다시 터미널을 엽니다.

### 8501 포트가 사용 중입니다

```powershell
streamlit run app.py --server.port 8502
```

브라우저에서 `http://localhost:8502`를 엽니다.

### 위치정보를 가져오지 못합니다

- 주소가 `localhost`인지 확인합니다.
- 브라우저 주소창 왼쪽의 권한 메뉴에서 위치를 허용합니다.
- 위치 기능이 없어도 생활권 프리셋으로 추천할 수 있습니다.

### 설치가 계속 실패합니다

`.venv` 폴더를 삭제한 뒤 가상환경 생성부터 다시 진행합니다. 회사·학교 네트워크가 설치를 차단하는 경우 다른 인터넷 연결을 사용하거나 네트워크 관리자에게 문의합니다.

## 최종 실행 명령 요약

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

정상 실행 주소: `http://localhost:8501`
