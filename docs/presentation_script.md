# 메디웨이 8분 발표·시연 대본

## 0:00~0:35 제목과 문제 제기

안녕하세요. 저희 프로젝트는 날씨와 대기질을 고려한 생활 의료 접근성 추천 서비스, 메디웨이입니다. 보통 의료기관을 찾을 때 가장 가까운 곳을 먼저 봅니다. 하지만 비가 오거나 미세먼지가 나쁜 날, 또는 고령자와 이동 취약자에게 같은 1km는 같은 부담이 아닙니다.

## 0:35~1:20 주제선정 이유·필요성

그래서 “오늘의 환경과 사용자의 특성까지 고려하면 어떤 의료기관이 더 가기 좋을까?”를 프로젝트 질문으로 정했습니다. 의료적 치료 적합성을 추천하려는 것이 아니라, 공개 데이터로 이동 부담을 비교해 일상적인 선택을 돕는 것이 목표입니다. 기존 거리 중심 검색과 달리 결과가 왜 달라졌는지도 함께 설명합니다.

## 1:20~2:20 데이터셋 설명

대상 지역은 부산광역시 금정구입니다. 제공된 MVP 엑셀에서 병원급 후보 15곳의 명부·진료과·운영 출처와 생활권별 보행경로 60건을 가져왔습니다. 이 중 부산대역·구서역·노포역 45건은 OSM 기반 근사 경로이고, 서동역 15건과 시설 접근성은 미확인으로 분리했습니다. 약국은 기존 공개자료 12곳을 유지했습니다.

## 2:20~2:55 추천 방식

종합 점수는 진료 조건 35%, 경로 편의 30%, 시설 접근성 20%, 운영정보 10%, 데이터 신뢰도 5%입니다. 날씨와 대기질은 시설별 야외 노출시간과 사용자 민감도에 적용합니다. 현재 경로와 접근성은 발표용 추정 프로필입니다.

## 2:55~3:40 시연 1 · 기본 추천

먼저 기본 추천입니다. [DEMO-01 선택 → 추천 결과 보기] 지온병원이 60.9점으로 1순위입니다. OSM 기반 근사 보행거리 4.11km와 이동·야외 노출시간, 공개 진료과가 함께 표시됩니다.

## 3:40~4:30 시연 2 · 고령자와 비

이번에는 구서역 생활권의 고령자와 비 12mm 조건입니다. [DEMO-02 선택 → 추천 결과 보기] 더케이부산병원이 76.9점으로 1순위입니다. 0.24km 근사 경로의 야외 노출에 비와 고령자 이동속도를 적용합니다.

## 4:30~5:25 시연 3 · 천식과 미세먼지

세 번째는 천식과 미세먼지 나쁨 조건입니다. [DEMO-03 선택 → 추천 결과 보기] 지온병원이 61.0점입니다. 내과 진료 근거와 경로별 야외 노출, 호흡기 민감 계수가 함께 반영됩니다.

## 5:25~6:20 시연 4 · 복합 특성

마지막은 서동 생활권의 고령자, 관절염과 고혈압, 비 조건입니다. [DEMO-04 선택 → 추천 결과 보기] 세웅병원이 65.3점입니다. 서동역 경로는 좌표 미확인이므로 화면에서 좌표 기반 추정으로 표시하고, 실제 지도 확인이 필요하다는 한계를 함께 보여줍니다.

## 6:20~7:00 지역 분석과 주요 기능

[지역 의료 현황 화면 이동] 금정구는 65세 이상 주민 비율이 28.9%입니다. 행정동별로는 선두구동이 44.2%로 가장 높습니다. 다만 앱의 병원·약국 수는 전체 공급량이 아니라 선별 스냅샷임을 화면에 명시했습니다. [추천 기준 안내 화면 이동] 사용자는 가중치, 점수 구간, 데이터 기준과 한계를 언제든 확인할 수 있습니다.

## 7:00~8:00 결론·차별점·한계

메디웨이는 지도 서비스의 대체재가 아니라 길찾기 전 의료 접근성 의사결정 레이어입니다. 질환 조건, 경로별 야외 노출, 시설 접근성과 운영정보를 비교한 뒤 외부 지도로 실제 길찾기를 연결합니다. 현재 경로·접근성은 `prototype_estimate`이며 다음 단계에서 실제 경로 API와 현장 검증 데이터로 교체할 수 있습니다.
