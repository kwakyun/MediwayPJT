# 예상 질의응답

## 가중치의 근거는 무엇인가요?

결론: 수업용 규칙 기반 프로토타입이며 임상적으로 검증된 가중치가 아닙니다. 진료 조건 35%, 경로 편의 30%, 시설 접근성 20%, 운영정보 10%, 데이터 신뢰도 5%로 분리했습니다. 네 대표 시나리오와 23개 자동 테스트로 계산 방향과 재현성을 검증했습니다.

## 실제 길찾기 거리인가요?

결론: 부산대역·구서역·노포역의 병원 15곳은 OSM/Valhalla 공개 데모 기반 근사 경로 45건을 사용합니다. 서동역 15건은 좌표 미확인이라 좌표 기반 추정값을 사용합니다. 어느 쪽도 정밀 상용 길찾기 경로로 표현하지 않습니다.

## 질환 정보로 병원을 추천해도 안전한가요?

결론: 의료적 치료 적합성을 추천하지 않습니다. 사용자가 선택한 질환을 공개 진료과목 명칭과 연결해 이동 접근성 점수의 일부로만 사용합니다. 실제 진료 가능 여부는 기관에 확인해야 하며, 진료과목이 없으면 임의 추정하지 않고 보수적으로 처리합니다.

## 데이터가 금정구 전체를 대표하나요?

결론: 인구 자료는 금정구 전체 공식 집계지만 시설은 발표용 선별 스냅샷 27곳입니다. 따라서 인구 1만 명당 시설 수는 전체 공급량이 아니라 앱 포함 표본을 설명하는 시연 지표입니다. 이 한계는 차트 바로 옆에 표시했습니다.

## 날씨와 대기질은 실시간인가요?

결론: 현재 제출 버전은 발표 재현성을 위해 저장한 모의 시나리오입니다. AirKorea 공식 등급 구간을 적용했지만 특정 날짜의 실제 관측값이라고 표현하지 않습니다. 실서비스에서는 기상청·AirKorea API와 캐시·장애 대체 경로를 함께 구성해야 합니다.

## 같은 건물의 마커가 왜 조금 떨어져 있나요?

결론: 원본 좌표는 보존하되, 같은 건물이나 도로 중심점으로 변환된 시설을 화면에서 구분하기 위해 지도 마커에만 작은 표시 오프셋을 적용했습니다. 거리 계산에는 원본 좌표를 사용합니다.

## 시설 접근성 점수가 실제 조사 결과인가요?

결론: 아닙니다. 제공된 엑셀에서 무단차·경사로·엘리베이터·장애인 주차·휠체어 접근은 모두 미검증입니다. 현재는 후보 간 동일한 중립값으로 처리하고, 지역 현황 화면에서 검증된 시설이 0곳임을 공개합니다.

## 다른 서비스와의 차별점은 무엇인가요?

결론: 일반 지도에서 길찾기하기 전에 질환·야외 노출·이동 취약성·시설 접근성으로 후보를 비교합니다. 선택 후 외부 지도에서 실제 경로를 확인하므로 지도 서비스와 보완 관계입니다.

## 팀 협업은 어떻게 했나요?

팀원별 이름, 담당 작업, 실제 산출물과 검토 내용을 협업 기록에 근거해 답해야 합니다. 현재 저장소에는 팀원 정보가 없어 제출 전 `docs/team_contribution.md`와 PPT 업무 분담 슬라이드를 실제 정보로 갱신해야 합니다.
